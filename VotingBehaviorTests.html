Planning Poker - Voting Behavior Test Suite

Test Controls

Instructions: Open browser console (F12) to see detailed logs. Test each scenario manually.

Test 1: Single Person Room

1. Create room with 1 person
2. Person votes
3. Expected: Cards should be disabled immediately
4. Expected: Results should show after countdown
5. Click "Clear votes"
6. Expected: Cards should be enabled again

Test 2: Multi-Person Room - Auto Show

1. Create room with 2+ people
2. First person votes
3. Expected: Cards remain enabled
4. Last person votes
5. Expected: Cards disabled, countdown starts
6. Expected: Results show after countdown
7. Click "Clear votes"
8. Expected: Cards enabled again

Test 3: Force Show Votes

1. Create room with 2+ people
2. Some people vote (not all)
3. Expected: Cards remain enabled
4. Click "Show votes" button
5. Expected: Cards should be disabled immediately
6. Expected: Results should show immediately
7. Click "Clear votes"
8. Expected: Cards enabled again

Test 4: Countdown = 0 (Immediate Show)

1. Set countdown to 0 seconds
2. Everyone votes
3. Expected: Cards disabled immediately
4. Expected: Results show immediately (no countdown)

Test 5: AutoShowVotes = false

1. Set AutoShowVotes to false (if possible)
2. Everyone votes
3. Expected: Cards remain enabled (no auto-show)
4. Click "Show votes"
5. Expected: Cards disabled, results show
